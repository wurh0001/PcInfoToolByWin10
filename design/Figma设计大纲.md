# PC Info Pro · Figma 设计大纲

设计源：[Figma 文件](https://www.figma.com/design/otKVFJ24sjAu4gdtpvCMM7?node-id=138-891)。

本文件仅保留界面结构与核心交互方向。详细尺寸、截图、设计变量及原型以 Figma 为准；本地详细交付资料不纳入 Git。此大纲不表示全部功能已在程序中实现。

## 界面结构

- 悬浮条：CPU 占用、CPU 温度、内存、网络吞吐与展开按钮。
- 系统概览：CPU、GPU、内存、磁盘、网络、传感器六项指标。
- 模块详情：即时读数、历史曲线、设备信息及相关统计。
- 单项直达：从悬浮条直接进入 CPU、温度、内存或网络详情。
- 偏好设置：外观、监控、常规三个分类。

## 视觉与布局

- 主题：亮色玻璃、纯白、深色、跟随系统；目前纯白主题是主要细化稿。
- 悬浮条基准 380×32 DIP，展开面板基准宽 360 DIP；高度随内容和屏幕可用空间调整。
- 展开布局支持“紧凑胶囊”和“完整长条”，由设置选择。
- 详情卡片替代当前指标长条，不重复显示同一指标；其他指标保持原顺序。
- 逻辑处理器使用水桶式填充，以高度和深浅表示利用率。

## 核心交互

- 同时最多展开一个模块；点击另一项切换，点击当前项收起。
- 首次呼出确定展开方向；本次展开期间保持锚点与方向，空间不足改为内部滚动。
- 未固定时点击外部关闭；固定后保持展开，关闭按钮与 Esc 仍有效。
- Esc 优先关闭设备菜单，其次设置，最后主面板。
- 磁盘名称提供设备下拉选择，相关曲线、读数及卷列表同步切换。
- 监控设置中的指标配置与显示提醒默认折叠。
- 展开/收起使用短过渡动画；开启减少动画时直接切换。

## 数据与实现原则

- 区分读取中、不支持、采样中断、设备断开和历史不足，不用假 0 代替缺失数据。
- 图表只绘制有效样本，数字刷新避免排版跳动。
- 支持 DPI、多显示器工作区、键盘操作及清晰的焦点状态。
- 实时采集、设备管理、设置持久化与窗口定位由 Win32/C++ 实现，Figma 原型仅表达设计状态。

## 设计稿分区

完整长条 → 紧凑胶囊 → 单项直达 → 双布局原型 → 磁盘选择 → 偏好设置 → 开发规范 → 旧版参考 → 异常数据 → 定位与关闭 → UI 细节。
